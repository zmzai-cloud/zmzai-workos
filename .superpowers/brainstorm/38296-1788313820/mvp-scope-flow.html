首版范围：只打通一条高频闭环

目标是让用户从目标到可用产物全程不丢上下文；不是在首版重造执行引擎。

数据与状态流
1 · 目标

创建目标、选择项目、附加背景资料

→
2 · Agent

创建执行任务，返回状态、检查点和产物

→
3 · 工作台

汇总队列；提示确认、失败与预算风险

→
4 · 结果

进入收件箱；可归档为项目知识或继续加工

MVP：本期交付
  • 目标、项目、状态与任务的关联模型
  • 工作台内创建 Agent 任务
  • 进行中／待确认／阻塞／完成的统一队列
  • 产物收件箱与项目知识归档
  • Relay 用量摘要和阈值预警
  • 任务失败或服务不可达时的明确降级状态
后续：明确不进首版
  • 可视化跨 Agent 编排器
  • 自动发布到第三方渠道
  • 多人协作与审批流
  • 自建模型网关或重复 Relay 计费能力
  • 复杂的知识编辑器

接口边界

工作台只保存目标、项目、引用关系与聚合视图；Agent 是任务执行和产物的权威来源；Relay 是用量与账单的权威来源。任何服务暂时不可用时，保留已知数据，并在对应模块标记“暂不可达”，不把它误显示为空。
